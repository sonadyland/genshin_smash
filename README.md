# 提瓦特大乱斗 · Elemental Clash

基于 React、TypeScript 与 Canvas 2D 的幻想横版动作小游戏。支持单人 CPU 试炼、共用键盘的本地双人对战，以及十分钟「秘境生存」。

## 运行

```sh
npm install
npm run dev
```

```sh
npm run build
npm run preview
```

## Docker 服务器部署

服务器安装 Docker Engine 和 Docker Compose 插件后，将项目（包括 `public` 美术资源和 `package-lock.json`）上传到服务器，在项目根目录执行：

```sh
docker compose up -d --build
```

浏览器访问 `http://服务器IP:18021/`。宿主机 **18021** 端口映射到容器内 **8080**；服务器防火墙或云安全组需要允许 TCP 18021。无需在服务器另行安装 Node.js。

镜像分为 Node.js 24 构建阶段和非 root Nginx 运行阶段，最终镜像仅包含构建产物与静态服务。容器启动后执行首页健康检查，并配置 `unless-stopped` 重启策略。页面和固定名称的美术资源会重新验证缓存，带内容哈希的 JS / CSS 使用长期缓存。应用部署于域名或 IP 的根路径 `/`，支持 SPA 路由刷新。

```sh
# 查看运行状态与健康状态
docker compose ps

# 查看日志
docker compose logs -f --tail=100 game

# 上传新版源码后，重新构建并更新服务
docker compose up -d --build

# 停止并移除容器
docker compose down
```

需要同时更新 Node / Nginx 基础镜像时，执行 `docker compose build --pull`，再执行 `docker compose up -d`。构建过程需要联网拉取基础镜像和 npm 依赖；运行时使用本地打包的美术资源，不需要图像生成 API 密钥。

## 音乐与音效

默认战斗配乐为《疾如猛火 Rapid as Wildfires》，来源是用户指定的[网易云音乐曲目](https://music.163.com/song?id=1492283139)。游戏使用其公开媒体外链在线播放，原始录音没有下载进项目或 Docker 镜像。进入战斗后循环播放；暂停、升级选择和切换到后台会暂停音乐，继续战斗时从原进度恢复。返回大厅会停止音乐并销毁本局音频，新开对局或重赛从头播放。

右上角和暂停菜单的「声音设置」提供独立的音乐、音效音量。**M** 或声音开关同时静音两路，音量滑条不会改变另一条音轨的设置。音量保留在当前页面会话内。攻击、命中、跳跃、闪避、技能、拾取与升级使用分层合成音效。

网易云外链需要玩家浏览器联网访问，可能受网络、地区、服务方链接策略或浏览器限制影响；播放失败时游戏自动切换到原创程序战斗配乐。声音面板会显示实际曲名、来源与加载状态，不将备用配乐标为原版 OST。浏览器要求手势授权时，点击「启用音乐」或重新开始/继续战斗。

也可用「导入本地音乐」选择浏览器可播放的音频文件：支持 80 MB 以内的 MP3、OGG、WAV、M4A、AAC、FLAC、OPUS；文件仅在当前页面会话内读取，不上传，刷新页面后恢复配置曲目。「恢复默认曲」立即重新使用项目的音乐配置。可在服务器部署自己的音频文件，并修改 `public/assets/audio/music.json`。`src` 的相对路径以该 JSON 所在目录为基准，例如音频放在 `public/assets/audio/liyue-battle.mp3`，填写 `"src": "liyue-battle.mp3"`；也支持 `/assets/audio/liyue-battle.mp3` 这样的同源绝对路径。`title` 用于显示曲名，`sourcePage` 可记录来源页面。将 `src` 设为空字符串会默认使用原创程序配乐。修改后重新构建镜像。

## 玩法

- 选择雷电将军、琴、优菈、迪卢克或降魔大圣·魈，设置对手、CPU 难度以及随机道具。
- 每人 3 条生命，每局 180 秒。累计伤害让对手更容易被击飞，越过上下左右边界即失去一条生命。
- 时间结束时先比较生命数，再比较伤害百分比；相同则平局。
- 用普攻制造机会，利用重击完成击杀。二段跳可返回平台，闪避可暂时躲开攻击。
- 魈使用长枪，技能「靖妖傩舞·坠星」仅可在空中释放：P1 先按 W 跳跃，再按 L；P2 先按 ↑，再按 / 或小键盘 3。短暂蓄势后垂直下坠，枪刺命中下方敌人，落地风浪震击两侧。注意在平台上方起手，空中下坠无法横向转向。
- 页面失去焦点时自动暂停，返回后手动继续。

| 操作 | P1 | P2 |
| --- | --- | --- |
| 左右移动 | A / D | ← / → |
| 跳跃 / 二段跳 | W | ↑ |
| 快速下落 / 下穿软平台 | S | ↓ |
| 普攻 | J | 小键盘 1 或 , |
| 重击 | K | 小键盘 2 或 . |
| 元素技能 | L | 小键盘 3 或 / |
| 战技（独立冷却） | I | 小键盘 5 或 '（单引号） |
| 闪避 | H | 小键盘 0 或右 Shift |
| 暂停 | Esc / P | Esc / P |
| 音乐与音效全静音 | M | M |

推荐桌面键盘、横屏游玩。手机可浏览和配置对局，战斗仍需外接键盘。

## 秘境生存

在大厅选择「秘境生存」，选定五名角色中的一人进入大地图。使用 P1 键位操作：A / D 移动，W 二段跳，S 下落或下穿平台，J 普攻，K 重击，L 元素技能，I 战技，H 闪避。所有招式由玩家手动释放；辅助效果只会由手动攻击触发，没有自动寻敌出招或自动转向。

- 地图宽 4,600 像素，包含高地、谷地、连通坡道与多层浮台。沿坡道直接登上高地，或从浮台跃入谷地，利用高低差选择攻击位置；镜头跟随角色，敌人从镜头外持续进入战场。
- 击败敌人后拾取经验，升级时暂停战斗并选择强化。一般提供三选一；主技能达到 4 级后立即在两条进化路线中免费二选一，同局只能选择一条路线。每局可重选两次普通强化，进化选择不能重抽。
- I 战技从 1 级起独立升级至 5 级，与 L 元素技能分别计算冷却。战技在 3、5 级获得新的攻击形态，各级同时强化伤害、范围与冷却；两招未满级时均会出现在普通升级选项中。战斗下方可查看战技等级与冷却，暂停及结算界面显示当前两招形态。
- 被动强化包括伤害、移动、范围、生命、减伤和经验吸取范围；最多携带两种辅助，辅助也可继续升级。生命强化增加生命上限并恢复对应生命。
- 生存计时只累计实际战斗时间，暂停和升级选择不会耗时。存活至 10:00 即通关，第 9 分钟出现的首领是额外挑战目标。
- 页面失焦或切换到后台时自动暂停；需要手动继续。Esc / P 暂停，M 静音。

| 角色 | 路线一 | 路线二 |
| --- | --- | --- |
| 雷电将军 | 连锁雷鸣：雷光命中后向附近敌人传导 | 断空雷刃：穿透雷刃折返，造成第二轮伤害 |
| 琴 | 聚风领域：旋风吸附、聚怪并切割 | 蒲公英守护：风场伤敌，并为场内角色恢复生命 |
| 优菈 | 霜轮旋舞：手动出招后短暂环绕冰刃并减速 | 碎冰终奏：攻击积累霜印，技能引爆 |
| 迪卢克 | 燎原之路：手动突进留下持续燃烧的火径 | 逆焰连斩：突进追加火弹与爆破区域 |
| 魈 | 镇岳：下坠后追加扩散冲击与风柱 | 凌空：命中返还跳跃次数并缩短冷却，由玩家继续起跳 |

魈的 L 仍然只能在空中释放，枪尖朝下。技能停在首先碰到的平台，不会穿过平台后才触发冲击；「凌空」不会自动反弹。角色、动作、背景与元素特效复用现有资源，敌人采用程序绘制的元素生物。

优菈的 L 冰浪旋斩现有更大的横向与纵向判定，冰浪特效同步扩大；生存中的霜轮覆盖范围也随强化增长。I 扇形冰晶更宽、更远，配合高低差清理前方敌群。

## 五名角色的新战技

战技在单人试炼、本地双人与秘境生存中均可手动释放。P1 / 生存模式使用 **I**，P2 使用 **小键盘 5** 或 **单引号 `'`**。以下冷却为基础值，3、5 级形态只适用于秘境生存；各战技配有独立人物动作帧与元素特效。

| 角色 | 战技与基础形态 | 基础冷却 | 生存 3 级形态 | 生存 5 级形态 |
| --- | --- | --- | --- | --- |
| 雷电将军 | 雷罚·天光：在前方召下贯穿上下空间的雷柱 | 4.5 秒 | 两道雷柱 | 三道雷柱 |
| 琴 | 风起·升流：上挑唤起风场，抬起前方敌人 | 5 秒 | 两道升流风场 | 两道风场大幅扩展 |
| 优菈 | 霜华·断浪：低位横扫发出三枚扇形冰晶，命中减速 | 4 秒 | 五枚冰晶 | 七枚冰晶 |
| 迪卢克 | 赤羽·燎空：上挑火剑，释放向前飞行的火鸟 | 5 秒 | 火鸟穿透沿途敌人 | 两只穿透火鸟 |
| 魈 | 风轮两立：沿当前朝向水平持枪突进 | 3.5 秒 | 追加一道穿透风刃 | 追加两道穿透风刃 |

魈的 I 可在地面或空中释放，方向由玩家朝向决定，不自动起跳或转向；L 仍是空中限定的枪尖朝下攻击。每次手动释放只产生有限时长的招式与特效。

## 结构与美术

- `src/pages/Home.tsx`：角色大厅、比赛设置和暂停 / 结果界面。
- `src/game/engine.ts`：固定 60 Hz 逻辑更新、物理、战斗、CPU、粒子和 HUD。
- `src/game/data.ts`：角色、招式、道具与场地数据。
- `src/game/survival-engine.ts`：生存模式的手动战斗、跟随镜头、怪潮、掉落和十分钟流程。
- `src/game/survival-data.ts`：生存地图、共享界面协议、角色进化和可验证的升级事务。
- `src/game/survival-render.ts`：生存地图、程序绘制怪物及复用动作与元素特效。
- `src/pages/SurvivalBattle.tsx`：生存 HUD、强化选择、暂停和结算界面。
- `src/pages/AudioSettings.tsx`：声音面板、独立音量、本地音频导入及来源状态。
- `src/game/audio.ts`：共享战斗音乐、浏览器播放授权与分层合成音效。
- `public/assets/audio/music.json`：战斗曲名与媒体地址配置。
- `src/game/art.ts`：立绘、动作图集与元素特效的本地预加载和 Canvas 绘制。
- `src/game/animation.ts`：由招式前摇、判定帧、后摇驱动的动作选帧，跟随游戏暂停与打击停顿。
- `public/assets/characters/*-v2.png` 与 `xiao-v3.png`：通过图像模型生成的五名角色透明全身立绘。
- `public/assets/backgrounds/liyue-dawn-v2.png`：本次生成的璃月晨曦场景。
- `public/assets/animations/*-actions-v3.png`：每人 16 格动作图集，共 80 格。包含待机、两个奔跑姿态、跳跃，以及普攻、重击、元素技能各四阶段。魈的技能动作由蓄势、下坠、落地、收枪阶段驱动。
- `public/assets/effects/elemental-bursts-v3.png`：雷、风、冰、火元素斩击与命中特效图集。
- `public/assets/effects/xiao-plunge-v3.png`：魈专用的青绿下坠枪风与落地风枪冲击图集，共 2 格。
- `public/assets/animations/*-secondary-v1.png`：五张独立战技动作图集，每人 4 帧，共 20 帧，包含蓄势、释放、延伸与收招；同名 JSON 保存取样区域及脚底锚点。
- `public/assets/effects/secondary-effects-v1.png`：五种战技效果与通用命中效果，共 6 格。资源及动作协议见[第二技能美术说明](public/assets/SECONDARY_SKILLS.md)。

美术为本项目生成的同人图像。角色与世界观来自《原神》，本项目为非官方同人游戏。战斗采用透明图集中的独立绘制姿态切换，配合残影、元素轨迹和命中火花；HUD 与大厅使用高分辨率立绘。原动作图集缺失时退回立绘，再退回程序绘制的角色；新增战技动作或特效资源不可用时直接使用程序备用绘制，避免把旧姿态作为新动作。玩法仍可运行。美术来源见 `public/assets` 中的生成清单，动作图集协议见 `public/assets/animations/README.md`。魈的视觉参考为[原神官方角色演示《Xiao: Doombane》](https://www.youtube.com/watch?v=sjozpa9DsZU)，本项目将下落攻击改编为平台格斗中的空中限定技能。
