# 钟离与芙宁娜正式动画资源

两位角色的正式资源分别位于 `zhongli-v1/`、`furina-v1/`。游戏只读取这里的 manifest 和 PNG，不加载预览页脚本或预览 metadata。

- 已批准立绘、J/L/I、岩柱、陨星和三位沙龙成员由预览资源逐字节复制。钟离 L 使用 `l-skill-cross-charge.png`；芙宁娜只使用新版 `*-proportions*.png`。
- 芙宁娜 L 按 A1 → D3 → D2 → D1 → B1–4 → C1–4 → D1 → D2 → D3 → A1 注册，保留脱帽、邀宾与复戴闭环，不使用坏帧 A2–4 / D4。
- 每人 8 张跑步、5 张起跳至落地、3 张侧闪姿势由内置 image_gen 生成，原始 PNG 未裁剪、重采样或重绘。准确提示词、输入参考和生成路径记录在 `summoner-generation.json`。
- 跑步已替换为 `run-v2.png`：以优菈的腿部衔接为主参考，按右脚接触、承重压缩、蹬伸、左脚短腾空，再交换支撑腿完成 8 帧闭环。两位角色跑动时收起武器，以小幅手臂动作保持平衡；钟离保留沉稳步幅，芙宁娜保留轻巧步态及一侧黑袜的服装一致性。
- `run-v2.json` 保存逐帧人工髋部地面投影、同排固定地平线及整张统一的人体标定。接地、压缩、蹬伸各帧共用地面，腾空帧保留脚底离地；不再跟随当前脚尖移动整个人物。帧权重沿用优菈的 `6/5/5/5 × 2`，仍由实际位移驱动 96 像素一个周期。原 `run.png` 保留但游戏不再请求。
- 两位角色目录中的 `run-v2-generation.json` 保留此次完整提示词、输入参考、原始路径和审片记录；芙宁娜的局部修复也保留逐次记录。实际 PNG 均为生成工具输出原文件，没有脚本像素加工。
- 每人 66 个注册帧：idle 2、run 8、jump 5、dodge 3、J 8、K 8、L 16、I 16。K 使用已批准突刺动作的蓄力及冲击节奏变化；J/K 没有伪造额外攻击形态。
- 多 atlas 的 `sourceScale` 是整帧统一比例标定。跑步与空中 atlas 使用整张固定骨架标定，蹲伏不会按当前包围框被放大。受击复用当前代的空中姿势。
- L/I 接触帧与真实技能释放时刻一致：钟离 L 第 10、I 第 12 帧；芙宁娜 L/I 第 11 帧。天星第 12 帧代表落地，空中下坠由战斗渲染在蓄力期展示。
- 三宠每张包含 4 张待机和 8 张攻击，攻击进度 0.5 对齐关键出手图。加载与释放由角色美术 lease 统一管理。

`scripts/build-summoner-art.mjs` 只复制 PNG 并重建注册 metadata。跑步必须读取已审阅的 `run-v2.json`，缺图、缺注册或尺寸不匹配会明确失败，不会重新按最低透明边界计算脚尖锚点或回退旧图。手工 source rect 避开邻格的剑尖、伸手和帽饰，全部游戏资源保持像素原样。

验收：`scripts/clip-animation-regression.mjs` 检查多 atlas 合约、施法释放帧、芙宁娜帽饰序列和实战速度下的帧可达性；新版跑步另验证两朝向、实际与升级移速下 8 帧完整可见，以及末帧返回首帧的距离相位。`scripts/art-regression.mjs` 检查 532 个正式注册帧的双朝向裁框/比例，以及召唤物帧与资源生命周期；新版跑步另检查真实 PNG 的格边透明余量、髋部注册、固定地面及腾空离地距离。

同尺寸审片：`/?animation=furina` 与 `/?animation=zhongli`，左侧为批准站姿，右侧为正式游戏动作。
