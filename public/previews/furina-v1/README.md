## 播放与审片

- L / I / J 按键与页面按钮选择动作。
- 暂停、上一帧、下一帧、时间滑块、0.5× / 0.25× 慢放。
- 完整效果、仅人物、仅三宠；左右朝向与脚底参考线。
- 「立绘比例对照」将原母版与当前动作并排显示，脚底对齐，以每张动作表的中立姿势标定固定身体高度。参考线标出母版的头顶（不含礼帽）、肩、胯、膝和脚底；欠身、弓步时保留真实姿势高度，不逐帧撑满外框。
- 比例对照时暂时隐藏三宠和水特效，便于观察头颅、颈肩、躯干和腿长；关闭即可恢复原显示方式。三宠独立视图不应用人物比例对照。
- 「仅三宠」采用独立动作周期，前 4 帧待机，后 8 帧蓄势、出手、回收；三个成员同步逐帧便于比较。
- 完整演出按成员错开登场与攻击；L 人物收势后保留舞台展示时间，让三宠完成各自一轮动作。这段审片时间不代表未来实战操作硬直。
- 仅人物模式将循环间隔缩为 0.60 秒，避免等待宠物演出空场。
- 礼帽完整包含于人物动作帧，不另外叠加第二顶帽子。
- 图片缺失时明确提示，不使用立绘摆动代替动作。

## 当前舞台时序

- L：人物动作 1.84 秒，随后 3.40 秒宾客演出；第 11 帧（C3）邀宾定姿到位，1.16 秒召唤，三宠分别延后 0 / 220 / 440 毫秒登场。扶帽、复戴移动帧 70–100 毫秒，欠身与邀宾定姿更久。
- I：人物动作 1.70 秒，随后 2.40 秒舞台余韵；三宠预先在场，第 11 帧（1.03 秒）手掌向前落拍时展开水幕。落拍过渡 70–80 毫秒，比起势更快。
- J：8 帧 0.815 秒，保留 0.60 秒循环间隔。前踏到刺出过渡 60–75 毫秒，第 5 帧（0.365 秒）剑尖到位时点亮水纹，特效落点按新剑尖位置重设。

- 每一张宠物表都根据实际透明分隔单独设置裁切矩形，保留伸展触手、长吻、抬高蟹钳。不会假定生成结果严格等距。
- 人物使用手工脚底锚点，剑尖与伸出的礼帽不参与中心定位。每张源图以同一骨架的中立姿态标定一个固定缩放倍率，整张 4 帧共用；没有单帧头部、躯干或腿长拉伸，欠身和前踏仍保留真实身高变化。

## 统一尺度标定

母版与动作都按自然头顶至脚底的站姿高度标定为 350 舞台像素；不包含帽、呆毛、举手或剑。每张图的全部姿势共用一个固定倍率，脚底使用手工锚点，欠身与弓步会自然低于母版。具体源图高度记录在 `metadata.json` 的 `standingBodyHeights` 中，属于肉眼标定的像素密度换算，不是精密人体测量。

## 实现边界

独立 HTML / CSS / Canvas 模块，无新增依赖。手机横屏保留同屏舞台和主播放条，竖屏自然堆叠滚动。系统偏好减少动态效果时初始暂停。

动作表支持多张 PNG：`sheets` 列出源图，`frames[].sheet` 指定帧来源，`rect` / `pivot` 只负责裁切与脚底定位。`sheetScales` 用中立姿势换算各张图的不同像素密度，同一源图全部帧共用一个倍率；不单独缩小头部、不拉长腿部，也不按弓步的外框高度动态缩放。头身比调整必须来自图像模型重新绘制的原始 PNG。

渲染使用浏览器原生 `drawImage` 九参数接口与 `requestAnimationFrame` 时间戳，参考 MDN 官方 Web 文档：

- <https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/drawImage>
- <https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame>
