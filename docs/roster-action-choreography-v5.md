# 四角色动作剧本：攻击、施法与释放

本轮把[雷电动作剧本](raiden-action-choreography.md)的设计方法应用于琴、优菈、迪卢克和魈：先核对技能产生什么效果，再决定身体怎样准备、释放、承接余势和回收。审计实际读取了 `src/game/data.ts`、`survival-data.ts`、`survival-engine.ts`、`engine.ts`、`animation.ts`、`clip-animation.ts` 和四份 v4 manifest，并逐张查看四角色在用的移动、J/K 及 L/I 图集。旧文档只作为历史设计记录。

本文件记录重绘决策、最终接入与验收结果，配套新图像素登记、引擎回归及独立 Architect 审查。本轮完成六个技能 clip 共 72 帧，加迪卢克三个近战 clip 共 24 帧，总计重绘 96 帧。其余已成立的动作、图片、阶段和 duration 权重保留。

## 动作共同约束

- 准备阶段表达重心和能量的来源，释放阶段立即表达真实攻击方向，随势承接惯性，回收恢复持械护身。披风和头发跟随身体，不能代替关节变化。
- 普通 J/K 每组 8 帧，按 `windup/contact/followthrough/recover` 分为 2/2/2/2；本轮重绘的 L/I 每组 12 帧，分为 4/2/3/3。继续使用各原 clip 的 duration 权重，不改变攻击总时长。
- 普通招式第一张 contact 即已发动。幸存者 J/K 在进入 contact 时仅执行一次近战伤害；不能在这张图仍把武器留在身后蓄力。L/I 的元素效果也在首 contact 触发，人物姿势不得晚到下一张图或 followthrough 才释放。
- 枪尖、剑尖按实际图像登记；脚点锚定物理基准。人物身高采用一个 clip 内固定的站立人体比例，不逐帧拉伸，不用整图旋转伪造动作，也不额外移动角色实体。
- 伤害、范围、冷却、手动输入、J/K 成功出招轮替、幸存者攻速升级和非致命受伤不中断均保持。基础包与变体回退契约保持。
- 元素大特效由现有引擎绘制；人物图不烘焙脱离身体的冰晶、火鸟或风刃数量。施法动作不无故添加斩击余光。

## 琴：剑锋定向，空手塑风

| 动作 | 准备 → 释放/运动 → 随势 → 回收 | 处理及理由 |
|---|---|---|
| 待机 | 低剑护身、重心居中 → 轻微呼吸 → 衣摆轻随 → 保持警戒 | 保留，稳定护势适合接入短促剑术。 |
| 跑动 | 前倾低护 → 交替蹬地与腾空 → 发尾后随 → 落脚接续 | 保留，双腿换步与武器稳定性已成立。 |
| 跳跃 | 屈膝 → 蹬地、收腿 → 顶点转为伸腿下落 → 屈膝落地 | 保留，剑低护，不伪装成空中攻击。 |
| 闪避 | 膝髋下沉 → 收肩贴地前闪 → 低位制动 → 回到低护 | 保留，收肢与移动意图明确。 |
| J 基础 | 肩侧短引剑 → 腕肘带动短横切 → 小幅跨体随挥 → 快速低护 | 保留，轻巧短斩。 |
| J 变化 | 肘收肋侧 → 前手直送剑尖 → 短促延伸 → 沿原线收剑 | 保留，与横切形成清晰区别。 |
| K 基础 | 宽支撑收剑 → 蹬后脚、长踏步压刺 → 深弓步承重 → 拉回重心收剑 | 保留，以腿髋参与和伸展幅度区别 J 直刺。 |
| K 变化 | 剑低收身后、腰胯扭转 → 转髋横扫 → 跨体停剑 → 回护 | 保留，与 K 基础刀路不同且首 contact 已前向攻击。 |
| L 风压剑 | 剑收肋侧、空掌内聚 → 剑沿身体中心线指前，空掌短推放压 → 胸肩轻回震、剑仍定向 → 收掌收腕 | **重绘 12 帧**。旧图长时间维持弓步直刺，与 J/K 太近；本轮让剑指向与空掌推压共同说明风压释放。 |
| I 风起·升流 | 膝稍屈、低手聚风 → 空掌托举，剑立起或斜上引流 → 站直维持风场 → 手掌收束、剑回低护 | **重绘 12 帧**。旧图直接上挑挥剑；改成升流召唤，`trail: none`，不添加上挑斩击弧。 |

L 对战是前向风压判定，基础前摇 12 tick；幸存者在首 contact 对前方执行 `210 × specialRange`、高度 150 的一次伤害。聚风领域随后在前方留下吸附旋风，蒲公英守护在自身附近留下治疗与伤敌风场。幸存者普通受击位移仍使用通用规则，动画不承诺额外强推距离。

I 基础前摇 12 tick；幸存者在前方 `80 × secondaryRange` 起生成升流柱，基础半径 78、高度 210、存续 85 tick，每个敌人每柱命中一次，非首领被抬升。I 三级变为两柱，五级进一步扩大风场。第一张 contact 已托起手掌并给出召唤指令；维持姿态不代表重复命中或新增持续施法机制。

## 优菈：旋舞环扫与扇形引霜分开

| 动作 | 准备 → 释放/运动 → 随势 → 回收 | 处理及理由 |
|---|---|---|
| 待机 | 大剑斜低护、重心稳定 → 轻微呼吸 → 披风轻随 → 保持护势 | 保留，沉重武器与从容站姿已成立。 |
| 跑动 | 重心前送、剑拖后侧 → 交替换步 → 披风沿后方展开 → 落脚承重 | 保留，武器重量和步态有区分。 |
| 跳跃 | 膝髋压低 → 持剑蹬地收腿 → 空中护身、伸腿准备 → 落地缓冲 | 保留，落地与升空阶段可辨。 |
| 闪避 | 大剑低收 → 屈身侧移 → 低重心制动 → 重新站稳 | 保留，不借闪避额外挥剑。 |
| J 基础 | 短转髋、剑收肩侧 → 紧凑横斩 → 剑随身体落低 → 快速护身 | 保留，短斩与 L 全身旋转区分。 |
| J 变化 | 提剑过肩 → 短斜下切 → 刃落前低位 → 提肘回护 | 保留，轻击幅度和回收紧凑。 |
| K 基础 | 宽步扭腰、剑收身后 → 半身重扫 → 剑与髋继续过线 → 缓慢回正 | 保留，重击的支撑与惯性明确。 |
| K 变化 | 双手举剑过顶 → 双脚承重向前下重劈 → 低位承接重剑 → 抽剑回护 | 保留，明确重劈不等于 L 改成竖斩。 |
| L 冰潮旋舞 | 舞步转髋、剑横收 → **保持原有旋转横斩** → 身体继续绕轴、覆盖两侧 → 降剑收步 | **完整保留原 `special.png`、登记与权重**。实际是双侧环扫，现有转身过程已经成立；历史 `special-turning-cleave` 不接入。 |
| I 霜华·断浪 | 大剑低位横护，空手向身侧收拢蓄霜 → **空掌向前开扇释放**，剑留在低护位 → 肩肘承接轻微回震 → 合掌回握、重心归位 | **重绘 12 帧**。原图读成蹲低直刺；本轮通过空手开扇区别 L 的全身旋斩，不再追加一次大剑挥斩。`trail: none`。 |

L 基础前摇 20 tick、主动窗 12 tick。幸存者首 contact 执行双侧 `205 × specialRange`、高度 `225 × specialRange` 的一次近战，并生成冰环。霜轮旋舞是在手动出招后追加环绕冰刃；碎冰终奏让手动伤害积累霜印，L 引爆范围内已有霜印。这些分支不能把人物动作改成另一种单侧竖劈，也不应烘焙到所有等级的人物图。

I 基础前摇 15 tick、主动窗 7 tick；首 contact 从身体前方发射扇形冰晶，命中减速 108 tick（1.8 秒）。一级 3 枚、三级 5 枚、五级 7 枚。首 contact 空掌已打开，发射方向和扇面由引擎决定；大剑不是发射弹丸前必须刺到敌人的近战武器。

## 迪卢克：短斩、重劈、冲撞和掀剑放鸟

|---|---|---|

| 跑动 | 压肩、剑贴身后拖 → 交替迈步 → 衣摆后拉 → 落脚承重 | 保留，大剑与躯干协同。 |
| 跳跃 | 屈膝持剑 → 蹬地收腿 → 剑保持身侧、伸腿落下 → 屈膝缓冲 | 保留，不混入劈砍。 |

| J 变化 | 反向短收剑、肘贴身 → 反手短斜切，首 contact 刃已前出 → 跨体收低 → 回护 | **重绘 8 帧**。旧 `jab-backhand` 首 contact 同样剑仍朝后；反手斩的准备、刀路与基础形态要可辨。 |

| K 变化 | 双手举剑过顶、后腿蓄力 → 踏步前下重劈，首 contact 剑已进入前方切线 → 膝髋压低承重 → 抽剑起身 | **重绘 8 帧**。旧 `smash-overhead` 第 3 格已是 contact，剑却仍停于头后高位；修正释放姿势，不推迟判定。 |
| L 黎明 | 沉肩屈膝、大剑后收 → 躯干整块前送，剑刃保持斜前稳定线冲进 → 前腿展开制动、承接惯性 → 收胯拖剑回护 | **重绘 12 帧**。旧图主动帧在低剑前伸、高位平刺、再次低压之间跳变；本轮固定冲撞刃线，以身体突进区别普通挥砍。 |
| I 赤羽·燎空 | 前侧掌中引火，手收回握剑蓄焰 → 双手从低位掀至前上放鸟 → 高位承重定势、胸肩轻回震 → 缓慢降剑回护 | **重绘 12 帧**。保留重剑放鸟身份，让掌中引火、回握蓄势与掀剑释放分工；最终图的空手在身体前侧引火，没有严格沿剑脊，因此按实际图记录。保留贴近人物的小焰，不采用空掌射鸟，不烘焙独立火鸟；余光为与剑路一致的 `arc`。 |

L 基础前摇 12 tick、主动窗 12 tick。对战按现有 dash 速度前冲，幸存者主动窗每 tick 追加水平位移与前方近战，各敌人由同一 hit 集合去重。燎原之路沿途留下火径，逆焰连斩追加火弹和爆破区。身体图不能表现挥完一刀后站住，冲刺过程的剑角须连续。

I 基础前摇 18 tick；首 contact 发出水平向前的火鸟。一级一只、三级可穿透、五级上下两只。第一张 contact 已开始将火势从低剑掀送至前方，不能到 followthrough 才出现发射意图。人物只表达引火、持剑释放与重剑回收，飞行方向、数量和穿透仍由引擎负责。

## 魈：枪法方向明确，水平突进强化收放

| 动作 | 准备 → 释放/运动 → 随势 → 回收 | 处理及理由 |
|---|---|---|
| 待机 | 长枪斜置身侧 → 低幅呼吸 → 飘带轻随 → 稳定守势 | 保留，枪杆方向清楚。 |
| 跑动 | 前倾、长枪斜收身后 → 交替蹬步 → 飘带后随 → 落脚接续 | 保留，行动与攻击的枪位不同。 |
| 跳跃 | 压膝 → 收腿跃起 → 枪仍斜护、准备落脚 → 落地收膝 | 保留，普通跳跃不提前播放向下坠刺。 |
| 闪避 | 收肩压低 → 紧凑前闪 → 前腿制动 → 起身护枪 | 保留，闪避与 I 水平主动攻击有区别。 |
| J 基础 | 后手收杆 → 前手导向、短促水平点刺 → 延伸一瞬 → 沿枪线回收 | 保留，枪尖前向与短促节奏明确。 |
| J 变化 | 枪从后肩短引 → 近身小幅横扫 → 枪尖落低 → 收回斜护 | 保留，短扫与点刺不同。 |
| K 基础 | 长杆过肩蓄力 → 转髋带动大幅枪扫 → 身体随杆展开 → 缓慢回护 | 保留，长杆横扫有重击幅度。 |
| K 变化 | 膝髋压低、枪尖收低 → 从低位向前上撩 → 肩胯抬升承接 → 降枪归位 | 保留，与基础横扫区分，首 contact 已前向发力。 |
| L 靖妖傩舞·坠星 | **仅空中**短暂停留，收膝立枪 → **枪尖垂直朝下**持续坠刺 → **真实落地后**屈膝承受冲击、两侧风浪 → 以枪支撑起身收势 | **完整保留原 `special.png`、登记与权重**。既有 `windup/dive/impact/recover` 已对应独立物理阶段；不能重画成横扫或在地面直接起跳。 |
| I 风轮两立 | 收枪靠后髋、压膝并转体 → 后腿驱动、前手导向，枪与躯干拉成水平长线 → 维持向前枪尖、展开前腿制动 → 后手收杆、胸肩回正 | **重绘 12 帧**。原图方向正确，但枪位和蹲姿变化过近；强化收枪、前冲与制动三个轮廓，保持 `trail: thrust`。 |

L 在地面按下会拒绝并提示先跳跃，不产生自动起跳。基础前摇 9 tick；dive 长度取决于真实地面碰撞，不能按固定图集时长提前落地。幸存者下降中可刺穿下方敌人，落地才产生双侧范围伤害；镇岳在落地追加风柱，凌空命中返还跳跃次数并缩短冷却，但由玩家再次主动起跳。

I 地面、空中均可使用，基础前摇 7 tick、主动窗 12 tick，沿当前朝向水平突进，不自动起跳、不自动转向。一级与二级没有额外风刃，三级一刃、五级两刃，均由引擎绘制。因此首 contact 必须已枪尖朝前开始突进，人物图不能画必有风刃，也不能把后半段收招读成向下坠落。

## 升级和时序验收

幸存者 L 等级提升伤害、范围并降低冷却，四级提供分支选择；I 等级提升伤害、范围、数量或穿透等形态并降低冷却。这些升级不改人物 clip 或触发额外一次人物挥砍。速度升级仍按原引擎规则缩短前摇和后摇；所有新图必须在两种模式、所有已有攻速等级下从首渲染 `t=1` 起可达。

| 角色 | J 首 contact | K 首 contact | L 首 contact / 特殊节点 | I 首 contact |
|---|---:|---:|---|---:|
| 琴 | 5 | 18 | 12：前向风压释放 | 12：升流召唤 |
| 优菈 | 8 | 26 | 20：双侧旋斩与冰环 | 15：冰晶扇形释放 |
| 迪卢克 | 7 | 24 | 12：主动冲进窗口开始 | 18：火鸟发射 |
| 魈 | 7 | 22 | 9：进入 dive；真实落地进入 impact | 7：水平枪突主动窗口开始 |

表内为 `data.ts` 基础 tick。幸存者前摇使用 `max(3, round(startup / speed))`，`speed = 1 + 0.035 × 轻盈步伐等级`；图像必须服从调整后的节点，不能为了表演延迟发招。迪卢克对战水平速度从 `t > startup` 的 dash 分支设置，首 contact 的攻击准备姿势仍须已释放。

验收需逐项核对：四阶段的剪影区别、武器握持和长度连续性、首 contact 与实际效果同步、左右镜像、112px 游戏尺寸可读性、透明边缘与完整武器留白、裁切与脚点、无程序化像素改写、已保留资源不变、J/K 轮替与 L/I 固定形态、两模式攻速相位可达，以及魈真实落地与优菈水平旋斩的硬约束。

历史背景见[五角色 v4 设计](roster-v4-animation-design.md)与[优菈基础动作](eula-v4-animation-design.md)。[优菈历史变化动作](eula-v4-attack-variants.md)中的 L/I 下劈方案仅为历史记录，不作为本轮接入依据。
