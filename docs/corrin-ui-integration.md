# 神威界面与加载接入

神威作为第九位斗士追加在现有角色之后，使用已批准的人形与白龙美术。首页展示双形态立绘及素材下载进度，出战时复用角色资源准备流程。没有改变原有八位角色的资源文件或内容哈希规则。

## 操作与状态

- J / K / I 在人形和白龙下使用各自招式，L 在地面或空中切换形态。
- 大厅列出两套招式；正式战斗读取引擎 `snapshot.corrin` 显示形态及当前招式，按变形实际提交时刻更新。
- 屏幕两侧触控布局保持原方式。L 显示龙化 / 复归，龙形 J / K / I 显示水弹 / 水息 / 水爆，完整招式名提供给无障碍标签。变形过程显示状态，动作是否可释放仍由引擎裁决。
- 生存界面的 L / I 冷却、暂停时的招式表跟随当前形态，变形不会刷新冷却。K 沿用攻击前后摇，不新增一套界面冷却。

## 资源与缓存

首页仅加入 `lobby/corrin.webp`。背景预取仍按雷电将军到撒拉，再到神威的顺序运行；只有进入游戏才解码完整人物资源。神威的生产清单遍历 32 个 clip 的 `sheets[].image`，按文件去重，不读取预览目录及历史候选图。下载、重试与按字节显示进度使用现有加载器。

## 动作审片

打开 `/?animation=corrin`，可选择人形 / 白龙、J / K / I / L 和移动动作。L 支持地面 / 空中变形，J 人形每轮循环三段；可慢放、暂停、逐 tick 前进和镜像。左侧是当前形态待机尺寸参照，右侧复用生产动画和剑光，白龙水脉从生产口部锚点释放。原母版对照保留在独立美术预览中。
