# 雷电将军：以旧版关键姿势重构连续动作

雷电将军的 v5 基础包参考项目旧版 `raiden-actions-v3.png` 与 `raiden-secondary-v1.png` 的持刀、重心与剪影，在清楚的关键姿势之间补充连续动作。当前在此包内用 v6 图集重新设计 L/I 共 24 帧，强调施法前的收束与释放时的展开；J/K 和移动等其余 56 帧保留。其余四名角色继续使用 v4。

## 动作方向

|动作|设计|
|---|---|
|J 轻击|肩上引刀、横向挥斩、跨体随挥、收回；变化形态仍为短促斩击|
|K 重击|恢复双手过顶蓄力、向前斜下重斩、压步低收；变化形态调整挥刀路径|
|L 梦想一刀|双腿近并、立刀凝神，随后踩开展身、转髋横切；回落重心、收脚归位，释放现有雷光波|
|I 雷罚·天光|刀始终保持低护，空手托掌聚雷、翻掌下压发令、短暂定势、收掌；前方出现现有竖直雷柱|
|移动|保持旧版低重心跑动和过顶持刀的空中剪影，补齐换步、腾空及着地|

刀身保持较长的太刀形状。贴图不烘焙大团紫光，余光和雷光波、雷柱继续由现有绘制层产生。J/K/L 使用显式 `trail: arc`，I 为 `none`，避免旧的基础 J 突刺默认值改变本轮刀光。

## 接入

- `src/game/animation-packs.json` 是运行时、素材回归与 Python 只读检查共同读取的在用包清单：雷电为 `raiden-v5`，优菈、琴、迪卢克、魈仍为各自 `v4`。
- 新包仍为 64 张基础动作、16 张 J/K 变化动作。六张图集共享解码，八个基础 clip 完整可用才启用；缺图回退旧版，可选变体分别回退基础动作。
- 所有 `sourceRect`、脚点、刀尖按生成图登记。每个 clip 使用固定身体比例，不逐帧拉伸，也不改变实体的位置。
- 保留原来的前摇、判定、后摇、伤害、范围、冷却、J/K 手动轮替、幸存者攻速与技能升级、受伤不打断规则。
- 没有为开发热更新状态修改资源加载器或模拟时钟。

JSON 静态导入由 [TypeScript 官方 `resolveJsonModule` 选项](https://www.typescriptlang.org/tsconfig/resolveJsonModule.html)支持，配置数据直接打包，不新增网络请求。

## v6 元素动作局部修订

本次重新绘制的是 L/I 两套动作共 24 帧，当前雷电包仍有 80 帧。每个动作遵循“准备、释放、余势、收束”，但使用不同身体语言：梦想一刀先将腿、手臂和刀收向身体中轴，再用踏步与转髋打开横切；雷罚由空手引导雷元素，握刀手保持低护，不用挥刀代替施法。

逐帧动作意图、保留动作的设计依据及独立姿势验收见[雷电将军动作剧本](raiden-action-choreography.md)，实际生成来源与最终像素登记见[本轮生成记录](raiden-elemental-v6-prompts.json)。

- L 第 1–4 帧为并腿立刀准备，第 5–6 帧踩开展身并横切，第 7–9 帧随挥回重心，第 10–12 帧收脚收刀。中段以刀尖围绕身体转动的切弧表现横切，避免多帧手臂与刀尖共线形成连续刺击。
- I 第 1–4 帧空手托掌，第 5–6 帧翻掌下压、第 7–9 帧定势回收、第 10–12 帧收掌。刀保持低护，`trail: none`，不绘制额外斩击弧线。
- 仍使用 `windup/contact/followthrough/recover` 的 4/2/3/3 分帧，释放姿态从第 5 帧即 `contact` 首帧出现，与现有雷光波、雷柱发射点一致。对战模式 L/I 分别在动作第 14/17 tick 释放，幸存者仍按原有攻速规则缩短前摇。
- 只将两个 clip 的图片引用切换为 `special-v6.png`、`secondary-v6.png`，按新画面重新登记裁切、脚点和刀尖；运行时仍读取 `raiden-v5/manifest.json`，无需复制其余图集或改动加载器。已打开的页面需要完整刷新才能释放原来的内存缓存。

本次不改变伤害、判定、冷却、技能升级或攻击时序，也不将所有元素技能统一改为挥砍。
