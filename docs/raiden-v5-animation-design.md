# 雷电将军：以旧版关键姿势重构连续动作

这次只升级雷电将军的角色动作。参考项目旧版 `raiden-actions-v3.png` 与 `raiden-secondary-v1.png` 的持刀、重心与剪影，在清楚的关键姿势之间补充连续动作。其余四名角色继续使用 v4。

## 动作方向

|动作|设计|
|---|---|
|J 轻击|肩上引刀、横向挥斩、跨体随挥、收回；变化形态仍为短促斩击|
|K 重击|恢复双手过顶蓄力、向前斜下重斩、压步低收；变化形态调整挥刀路径|
|L 梦想一刀|胸前竖刀蓄势、向前拔刀横斩、弓步随挥、低位收刀；原地释放现有雷光波|
|I 雷罚·天光|斜向提刀、单臂高举刀尖朝天、前送收刀、回到低护；前方出现现有竖直雷柱|
|移动|保持旧版低重心跑动和过顶持刀的空中剪影，补齐换步、腾空及着地|

刀身保持较长的太刀形状。贴图不烘焙大团紫光，余光和雷光波、雷柱继续由现有绘制层产生。J/K/L 使用显式 `trail: arc`，I 为 `none`，避免旧的基础 J 突刺默认值改变本轮刀光。

## 接入

- `src/game/animation-packs.json` 是运行时、素材回归与 Python 只读检查共同读取的在用包清单：雷电为 `raiden-v5`，优菈、琴、迪卢克、魈仍为各自 `v4`。
- 新包仍为 64 张基础动作、16 张 J/K 变化动作。六张图集共享解码，八个基础 clip 完整可用才启用；缺图回退旧版，可选变体分别回退基础动作。
- 所有 `sourceRect`、脚点、刀尖按生成图登记。每个 clip 使用固定身体比例，不逐帧拉伸，也不改变实体的位置。
- 保留原来的前摇、判定、后摇、伤害、范围、冷却、J/K 手动轮替、幸存者攻速与技能升级、受伤不打断规则。
- 没有为开发热更新状态修改资源加载器或模拟时钟。

JSON 静态导入由 [TypeScript 官方 `resolveJsonModule` 选项](https://www.typescriptlang.org/tsconfig/resolveJsonModule.html)支持，配置数据直接打包，不新增网络请求。
