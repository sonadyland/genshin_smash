# 女神威双形态正式玩法

2026-10-15：将已经批准的母版比例 v2 美术接入现有 Canvas 游戏。角色 id 为 `corrin`，菜单显示「神威 · 夜刀与白龙」。模式包括人机、双人对战、幸存者、战术试炼与遗迹漫游。全部招式继续由玩家手动触发。

## 动作和判定

| 按键 | 人形 | 白龙 |
| --- | --- | --- |
| J | 夜刀神三连：斜下斩、反手横扫、短突刺，逐次按键推进 | 从真实嘴部射出定向水脉弹 |
| K | 慢举剑、快速下劈的「夜刀神 · 断空」 | 向前方吐出持续 24 模拟帧的贯穿水息，基础 3 次脉冲 |
| I | 左臂龙化后沿登记的龙牙起点—尖端穿刺 | 仰首抛出水球，真实重力飞行，碰到敌人或地形后水爆 |
| L | 变为白龙 | 复归人形 |

游戏以 60 Hz 更新。J/K 沿用普通攻击与重击的动作间隔，不额外加冷却。L 基础冷却 2.5 秒，I 基础冷却 6 秒；两个形态共享各自冷却。三段 J 不自动追击，超过连段输入窗口后回到第一段。

`src/game/corrin.ts` 是两引擎共用的招式数据和水系效果模拟。美术按招式 startup / active / endlag 映射准备、释放与回收；开始伤害的时刻与注册释放帧一致。攻击开始时锁定来源形态和三连段序号，动作中不能通过 L 换形跳过后摇。

白龙 J/K/I 关闭通用近战判定和其他角色的 I 释放适配，避免远程施法同时产生看不见的近战。水弹从嘴部出发，沿固定 8 帧可见弧线进入脚底上方 35 像素的飞行区域，不追踪目标。水息直接以当前动作嘴部为起点，其可见终点在实体地形前截断；21 像素基础半径同时用于图形高度和伤害范围，能接触低矮地面敌人。白龙水球命中后只爆破一次，每个目标只结算一次该次水爆，圆形范围和地形视线均参与检查。

人形 I 使用 `getCorrinFangSegment` 的真实左臂起点与龙牙尖端，沿可见刺出的高度判定。普通蓝色史莱姆现为约 92 像素高（实体目标高 89.6 像素），略小于 112 像素的人形角色，同层地面即可接触龙牙；金色精英史莱姆仍更大。调整只改变这两类史莱姆的统一绘制／实体尺寸，脚底坐标、生命、伤害和招式判定规则不变。真正低于龙牙的目标仍不会被隐形低位判定击中。

## 变形生命周期

形态属于每名 fighter / survivor，不修改共享 `CHARACTERS`。变形锁定 from、to、起手时是否在空中、总帧数及提交点。地面双向均 46 帧，空中人→龙 34 帧、龙→人 32 帧；提交点分别为 24、15、17、9 帧，对应批准的变形素材相位。

变形期间锁定移动方向、跳跃、闪避和 J/K/I/L 新出招，继续已有速度、重力和平台碰撞，不改脚底坐标、空中跳跃余额、I 冷却或当前朝向。自然落地仍按既有物理规则恢复跳跃次数。连续按 L 不会刷新状态或获得额外跳跃。

对战受击取消变形动作，并停留在提交点之前的来源形态或之后的目标形态，不退还冷却。幸存者受伤沿用原有四帧停顿，不取消攻击、变形、速度或跳跃状态。暂停和升级冻结整个模拟；死亡、重开、复活和销毁清理本人效果与形态。双神威对战的形态、连段和水系效果按 ownerId 隔离。CPU 会根据距离切换人龙，白龙在中距离优先使用远程招式。

## 幸存者成长

- 「人龙精修」提高两形态手动攻击伤害，并缩短 L 冷却；4 级选择一个分支。
- 「J · 夜刀与水弹」同时提高人形三连和水弹伤害；2 级获得水弹穿透，3 级获得双发。
- 「K · 断空与水息」同时提高下劈和水息伤害；3 级将同一吐息时段提高到 4 次脉冲。
- 「I · 龙牙与水爆」提高两形态 I 伤害、扩大龙牙接触宽度和水爆范围，并缩短共享冷却。
- 「夜刀共鸣」提高人形伤害并增加白龙水弹穿透；「奔涌水脉」将水弹变为三发扇形、增加水息脉冲并扩大水爆。

这些升级修改实际手动攻击，不产生自动攻击。独有 J/K 卡不会进入其他角色的升级池。`getCorrinSurvivalProfile` 同时驱动说明和模拟数值。两个引擎的 `getSnapshot().corrin` 提供当前形态、变形中状态与 J/K/L/I 动态名称，移动端直接显示这些名称。
